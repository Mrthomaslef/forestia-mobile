Forestia

Streaming depuis le Mac via Moonlight

Première fois : créer le raccourci (1 min)
  1. Ouvre l'app Raccourcis → +
  2. Ajoute l'action Ouvrir l'app → choisis Moonlight
  3. Nomme le raccourci exactement Forestia

Ensuite, dans Moonlight : Forestia-Mac → Forestia (le jeu se lance en plein écran). Clavier : tape l'écran avec 3 doigts.
